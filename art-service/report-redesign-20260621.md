# ELURA Report Redesign - Simple Version

The report answers only three questions:

1. Are we getting more reaction?
2. Is the right audience reacting?
3. What should we change tomorrow?

## Page Structure

### 1. Today's Takeaway

One short sentence.

Example:

`Saves are rising, but profile visits are not. Keep the color-board format and make the last slide more profile-curious.`

### 2. 7-Day Direction

Show three cards only:

- `Overall reaction`: up / flat / down
- `Target audience`: up / flat / down
- `Profile movement`: up / flat / down

Each card gets one reason line. No long tables.

### 3. What Worked

Show the top 3 posts from the last 7 days.

For each post:

- first slide image
- views
- saves
- shares
- profile visits if available
- target fit if available
- one plain takeaway

### 4. Tomorrow

Four lines only:

- S1:
- S2:
- S3:
- S4:

Each line says what to try next.

## Move To Debug

These should not be on the main page:

- long archive navigation
- full site bot filtering explanation
- all 12:00 research cards
- long cumulative insight lists
- every demographic bar
- metadata explanations

Keep them only under a `Debug` section or separate archive.

## Rule

If a number appears, it must lead to a takeaway.  
If there is no takeaway, hide the number.
