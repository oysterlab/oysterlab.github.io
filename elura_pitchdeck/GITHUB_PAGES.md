# ELURA Pitch Deck — GitHub Pages

Static presentation viewer for the 19-slide ELURA image deck.

## Published path

`https://oysterlab.github.io/elura_pitchdeck/`

## Controls

- `←` / `→`, `Page Up` / `Page Down`, or `Space`: navigate
- `Home` / `End`: first or last slide
- `O`: overview grid
- `F`: full screen
- Swipe left / right on touch devices

The site has no build step or external dependencies. GitHub Pages can serve the folder directly.
