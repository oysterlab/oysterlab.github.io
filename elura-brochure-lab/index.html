Research Memo

어떤 감성이 먹힐 가능성이 높은가

현재 ELURA의 내부 데이터는 25-34세와 여성 비중이 강하지만, 북미/유럽 도달은 아직 약하다. 그래서 브로슈어는 지나치게 차갑거나 미술관 같은 럭셔리보다, 실제 임대방과 작은 가구의 단서를 고급스럽게 해석하는 방향이 유리하다.

핵심은 “비싼 결과물”을 말하는 것이 아니라, 사용자의 방에서 이미 보이는 취향을 발견해 주는 편집 경험이다. 빈 벽, 낮은 선반, 거울 가장자리, 침대 옆 조도, 책 더미 같은 생활 단서를 아트의 역할로 번역해야 한다.

명품 하우스 문법

Dior Maison은 집을 제품 카테고리가 아니라 art de vivre와 물성의 세계로 묶는다. ELURA에는 “팔레트, 텍스타일, 오브제, 조도”를 하나의 방 언어로 묶는 방식이 맞다.

장인적 오브제 문법

Louis Vuitton Objets Nomades는 기능적 가구를 디자이너, 재료, 이동성, 장인성의 이야기로 올린다. ELURA도 “벽에 거는 그림”이 아니라 “방의 행동을 바꾸는 오브제”로 설명해야 한다.

하우스 코드 문법

Chanel식 스토리텔링은 반복되는 상징, 장소, 챕터의 힘이 강하다. ELURA에는 사용자의 방에서 반복되는 색, 선, 물건, 시선을 개인 코드로 명명하는 구조가 필요하다.

소셜 저장 문법

TikTok 레퍼런스의 저장 동인은 컬러 콤보, 맛 취향 인벤토리, 실제 방 크롭이다. 브로슈어도 PDF로는 고급 잡지처럼 보이되, 화면에서는 저장 가능한 보드처럼 즉시 읽혀야 한다.

Demographic Fit Thesis

가장 강한 방향은 lived-in couture다.

여성 비중과 25-34세 비중이 높은 현재 ELURA에는 차갑고 비어 있는 갤러리형 럭셔리보다, 실제 방의 생활 밀도를 남기면서 색·물성·시선을 명품 편집처럼 정리하는 브로슈어가 더 적합하다.

업로드 사진은 취향 설문이 아니라 공간 증거다

사용자가 올리는 한 장의 방 사진은 스타일 선택지가 아니라, 이미 살고 있는 방식의 증거다. ELURA의 브로슈어는 그 증거를 조용히 판독하고, 한 점의 아트가 맡을 역할을 고급 납품서처럼 정리해야 한다.

02 / Read

color, line, object, light, behavior

사진에서 반복되는 색, 프레임 선, 작은 물건, 조도, 동선을 공간 신호로 추출한다.

03 / Assign

04 / Story

name the private code

Signal To Story Generation Schema

브로슈어 생성은 취향 라벨링이 아니라 증거 번역이다

사용자가 방 사진을 올리면 ELURA는 “모던”, “미니멀”, “코지” 같은 라벨을 먼저 붙이지 않는다. 사진 속 반복 증거를 읽고, 그 증거가 어떤 아트 역할과 스토리 문장으로 바뀌어야 하는지 순서대로 변환한다.

Generation Rule signal first, style second, purchase proof last

방의 증거가 없으면 문장도 만들지 않는다. 모든 브로슈어 문장은 사진 안의 색, 선, 물건, 빛, 행동 중 하나에 연결되어야 한다.

Field 01

Visible Signals

색면, 프레임 선, 조도, 재료, 반복 물건, 시선이 멈추는 지점을 추출한다.

example: dark frame, towel, warm wood, mirror edge
Field 02

Room Role

그 벽이 쉬는 곳인지, 들어오는 곳인지, 앉는 곳인지, 정리되는 곳인지 먼저 정한다.

example: daily pause, entry cue, bedside anchor
Field 03

Art Function

아트가 맡을 일을 하나만 지정한다. 정지점, 균형추, 온도 조절, 시선 고정 중 하나로 좁힌다.

example: make the pause visible
Field 04

Palette Logic

Dominant, Counter Tone, Quiet Field, Anchor로 색을 분리해 PDF에서 바로 판단 가능하게 한다.

example: warm wood anchor with cool blue field
Field 05

Private Code Name

사용자의 방에서 반복되는 단서를 하우스 코드처럼 이름 붙여 브로슈어의 챕터 제목으로 만든다.

example: The Mirror Edge, The Warm Object
Field 06

Delivery Proof

마지막에는 감성 문장이 아니라 납품 판단을 준다. 한 벽 역할, 두 아트 루트, 하나의 printable PDF로 닫는다.

example: one wall role, two art routes
Luxury Copy System

문장은 과장하지 않고, 판정은 선명해야 한다

ELURA의 브로슈어 문체는 광고 카피보다 개인 큐레이터의 납품 문장에 가깝다. 사용자의 방을 칭찬으로 포장하지 않고, 사진 속 증거를 근거로 아트의 역할을 정한다.

Voice Rule quiet confidence, specific evidence, no generic decor language

“예쁘다”보다 “왜 이 벽에 필요한가”를 먼저 말한다.

Use

evidence-based sentence

거울의 검은 선과 수건의 부드러운 물성 때문에, 이 벽은 강한 색보다 얇은 구조가 먼저 필요하다.

Use

role-first recommendation

이 그림의 역할은 공간을 장식하는 것이 아니라, 매일 반복되는 정리의 순간을 보이게 만드는 것이다.

Use

limited choice language

이 방에는 세 가지 옵션이 아니라 두 가지 루트만 남긴다. 조용한 구조와 조금 더 선명한 온도다.

13:00 / Design Test 03

Objets Nomades Room

사용자의 방은 정적인 배경이 아니라 매일 이동하는 오브제들의 무대다. 아트는 선반, 램프, 책 더미, 열쇠, 의자와 함께 움직임의 질서를 잡는 중심 오브제가 된다.

Not a gallery wall. A portable order for daily objects.

사용자가 방 사진을 올리면 ELURA는 먼저 “움직이는 물건”을 읽는다. 매일 잡는 컵, 내려놓는 열쇠, 켜는 램프, 밀어 넣는 의자. 그림은 그 움직임을 고급스럽게 정리하는 중심축이어야 한다.

Material

dark wood, paper, ceramic, linen

공간의 값비싼 느낌은 광택보다 반복되는 촉감에서 생긴다. 아트는 이 물성들을 방해하지 않는 무광 면과 깊은 색으로 들어간다.

Movement

reach, set down, return, glance

작품 배치는 벽 중앙이 아니라 몸이 자주 돌아오는 동작을 기준으로 잡는다. 그래서 작은 선반 위 그림도 큰 벽화보다 설득력이 생긴다.

Client Promise

ELURA의 역할은 새 물건을 강요하는 것이 아니라, 방 안의 물건들이 이미 말하고 있는 취향을 하나의 아트 언어로 번역하는 것이다.

Placement Proof

명품스러운 배치는 벽 중앙을 찾는 일이 아니다. 매일 손이 가는 지점, 돌아오는 시선, 내려놓는 물건과 작품이 만날 때 설득력이 생긴다.

ELURA는 “minimal”, “cozy”, “modern” 같은 외부 취향표를 붙이지 않는다. 사용자의 방 사진에서 반복되는 선, 물성, 색, 시선을 개인 코드로 명명한다.

Saveable Crop Rule

leave one lived object visible

사용자의 방이 저장되는 이유는 완벽해서가 아니라 실제로 살고 있는 증거가 남아 있기 때문이다. 컵, 수건, 책 더미 중 하나는 반드시 프레임 안에 남긴다.

Drop: sterile minimalism, generic gallery wall advice, over-explaining the emotional premise.

Editorial Angle

A room that looks used is not less luxurious.
